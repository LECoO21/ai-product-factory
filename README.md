# AI 产品工厂

一个本地优先、可控制、可观察、可恢复的 AI 数字产品生产流水线。工厂使用 Pi Agent + DeepSeek 执行生产任务，由确定性控制器管理状态、权限和质量闸门；小游戏只是首台试产样机，不是工厂的默认产品类型。

## 项目入口

- [AI 产品工厂说明与运行方法](./AI产品工厂/README.md)
- [AI 产品工厂源码](./AI产品工厂/)

## 最高工程规范

项目必须完整遵循三份内部原始手册，项目内的摘要和派生文档不能替代原文。原始手册仅保留在内部工作区，不随公开仓库分发。

## 本地运行

```bash
cd AI产品工厂
npm install
cp .env.example .env
npm run dev
```

不配置 `DEEPSEEK_API_KEY` 也可以创建项目、编译蓝图和验证阻塞恢复；真实 Agent 推理需要在本地 `.env` 中配置该密钥。

内部维护者在具备三份原始手册的工作区中，还应先运行 `npm run manuals:verify`。
