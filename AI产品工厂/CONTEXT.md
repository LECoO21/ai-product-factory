# AI 产品工厂领域语言

本上下文描述 AI 产品从需求输入到发布候选的生产过程。它用于让 WebUI、生产控制器、Agent 和验收记录使用同一套词汇。

## 项目与生产

**产品项目（Product Project）**：
一次独立的 AI 产品生产对象，拥有自己的 PRD、代码工作区、生产记录和交付物。
_Avoid_: 任务、会话、仓库

**生产批次（Production Run）**：
产品项目的一次连续生产尝试，可成功、失败、取消或从检查点恢复。
_Avoid_: 对话、请求、执行一下

**生产阶段（Stage）**：
产品从接单到发布候选所处的稳定生命周期位置，如“核心能力生产”或“正式前端生产”。
_Avoid_: 步骤、页面

**工位（Station）**：
生产阶段内职责固定、输入输出明确的一类工作岗位，如“技术适配工位”或“质量验收工位”。
_Avoid_: Agent、子任务、功能模块

**生产单（Work Order）**：
发给工位的一次结构化工作指令，包含目标、输入、允许工具、约束、预算和验收条件。
_Avoid_: Prompt、需求描述

**产品画像（Product Profile）**：
从 PRD 提取的产品事实集合，描述用户任务、交互形态、终端、数据、产物、风险和运行特征，不用单一产品类别代替事实。
_Avoid_: 产品标签、项目类型枚举

**生产蓝图（Production Blueprint）**：
根据产品画像编译出的本项目生产路线，规定需要哪些阶段、工位、能力包和质量闸门。
_Avoid_: 固定流水线、游戏模板

**能力包（Capability Pack）**：
可组合加入生产蓝图的一组专用工位规则、工具权限和验收要求，如 Agent、媒体、实时交互或游戏体验能力包。
_Avoid_: 产品模板、插件

## 控制与验收

**生产控制器（Production Controller）**：
决定生产批次何时进入、暂停、恢复或退出某个状态的唯一事实来源。
_Avoid_: 总控大模型、超级 Agent

**人工闸门（Human Gate）**：
生产继续前必须由产品负责人明确批准的决策点，用于范围、费用、效果或发布确认。
_Avoid_: 弹窗、审批流

**质量闸门（Quality Gate）**：
由确定性检查和可追溯证据判定是否允许进入下一生产阶段的门槛。
_Avoid_: Agent 自评、完成提示

**检查点（Checkpoint）**：
生产批次可安全恢复的位置，记录当时的阶段、工位、产物、事件和待处理事项。
_Avoid_: 聊天记录、缓存

**生产事件（Production Event）**：
生产过程中不可变的事实记录，如工位开始、工具被调用、测试失败或人工批准。
_Avoid_: 日志文本、消息

## 交付物

**生产档案（Production Record）**：
产品项目累积的结构化事实集合，包括范围、决定、生产事件、闸门证据和版本结果。
_Avoid_: README、聊天历史

**产物（Artifact）**：
工位产生并登记的可查看结果，如文档、代码变更、测试报告、截图、构建包或访问地址。
_Avoid_: 输出、回复

**发布候选（Release Candidate）**：
已经通过当前范围内全部质量闸门、等待最终发布确认的产品版本。
_Avoid_: 已上线、基本完成

**试产（Pilot Run）**：
用真实产品验证工厂本身是否能稳定生产的批次；首个试产对象为小游戏，但试产对象不定义工厂能力边界。
_Avoid_: Demo、假数据演示
