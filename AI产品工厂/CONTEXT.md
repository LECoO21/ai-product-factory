# AI 产品工厂领域语言

本上下文描述 AI 产品从需求输入到发布候选的生产过程。它用于让 WebUI、生产控制器、Agent 和验收记录使用同一套词汇。

## 项目与生产

**产品项目（Product Project）**：
一次独立的 AI 产品生产对象，拥有自己的 PRD、代码工作区、生产记录和交付物。
_Avoid_: 任务、会话、仓库

**生产批次（Production Run）**：
产品项目的一次连续生产尝试，可成功、失败、取消或从检查点恢复。
_Avoid_: 对话、请求、执行一下

**生产阶段（Stage）**：
产品从接单到发布候选所处的稳定生命周期位置，如“核心能力生产”或“正式前端生产”。
_Avoid_: 步骤、页面

**工位（Station）**：
生产阶段内职责固定、输入输出明确的一类工作岗位，如“技术适配工位”或“质量验收工位”。
_Avoid_: Agent、子任务、功能模块

**生产单（Work Order）**：
发给工位的一次结构化工作指令，包含目标、输入、允许工具、约束、预算和验收条件。
_Avoid_: Prompt、需求描述

**产品画像（Product Profile）**：
从 PRD 提取的产品事实集合，描述用户任务、交互形态、终端、数据、产物、风险和运行特征，不用单一产品类别代替事实。
_Avoid_: 产品标签、项目类型枚举

**生产蓝图（Production Blueprint）**：
根据产品画像和 Harness 五要素编译出的版本化生产方案，规定产品架构、阶段、能力包、执行组件和质量闸门。
_Avoid_: 固定流水线、游戏模板

**能力包（Capability Pack）**：
可组合加入生产蓝图的一组专用工位规则、工具权限和验收要求，如 Agent、媒体、实时交互或游戏体验能力包。
_Avoid_: 产品模板、插件

## Agent 与执行

**工厂 Agent（Factory Agent）**：
在当前生产目标和授权边界内进行推理、规划并请求工具行动的模型驱动执行者；它不是生产状态或质量结论的事实来源。
_Avoid_: 总控大模型、聊天机器人、生产控制器

**Agent Harness**：
承载工厂 Agent 的受控执行环境，由工具、知识、观察、行动接口和权限共同组成。
_Avoid_: Prompt、模型封装、固定流水线

**目标产品工作区（Target Product Workspace）**：
某个产品项目被授权用于保存和修改代码、资产与生产结果的隔离范围。
_Avoid_: 用户目录、整个工作区、随便一个文件夹

**工具请求（Tool Request）**：
工厂 Agent 在当前生产单内提出的一次结构化外部行动申请，本身不代表行动已经发生。
_Avoid_: 命令文本、Agent 决定、工具结果

**工具结果（Tool Result）**：
工具请求被允许、拒绝、成功或失败后形成的一次结构化事实记录。
_Avoid_: Agent 总结、聊天回复、完成声明

**生产工作流（Production Workflow）**：
把已确认生产蓝图转换成可执行、可恢复的阶段与任务依赖图；固定编排由代码拥有，阶段内动作由工厂 Agent 决定。
_Avoid_: 聊天步骤、Prompt 链、页面流程

**完成目标（Completion Goal）**：
为一次生产任务定义结束状态、验证方式和限制条件的可检查合同。
_Avoid_: Agent 说做完了、停止回复

## 控制与验收

**生产控制器（Production Controller）**：
决定生产批次何时进入、暂停、恢复或退出某个状态的唯一事实来源。
_Avoid_: 总控大模型、超级 Agent

**人工闸门（Human Gate）**：
生产继续前必须由产品负责人明确批准的决策点，用于范围、费用、效果或发布确认。
_Avoid_: 弹窗、审批流

**质量闸门（Quality Gate）**：
由确定性检查和可追溯证据判定是否允许进入下一生产阶段的门槛。
_Avoid_: Agent 自评、完成提示

**质量证据（Quality Evidence）**：
与明确完成目标和产物版本绑定、可追溯且可复查的观察事实。
_Avoid_: Agent 自评、口头保证、空结果

**权限裁决（Permission Decision）**：
工具请求执行前形成的允许、等待人工确认或拒绝结论。
_Avoid_: 前端隐藏按钮、Agent 自我约束、默认放行

**检查点（Checkpoint）**：
生产批次可安全恢复的位置，记录当时的阶段、工位、产物、事件和待处理事项。
_Avoid_: 聊天记录、缓存

**生产事件（Production Event）**：
生产过程中不可变的事实记录，如工位开始、工具被调用、测试失败或人工批准。
_Avoid_: 日志文本、消息

**协议线程（Protocol Thread）**：
运行协议中的持续上下文身份，第一版与产品项目一一对应。它只用于连接 Core、传输和恢复，不替代“产品项目”这一业务名称。
_Avoid_: 新产品项目、聊天窗口

**协议轮次（Protocol Turn）**：
运行协议中的一次有明确开始和终态的执行身份，第一版与生产批次一一对应。生产阶段仍是业务生命周期位置。
_Avoid_: 新生产阶段、模型单次回复

**运行核心（Runtime Core）**：
位于传输、工位处理器、Agent 和档案之间的确定性执行内核；选择已注册处理器、发布协议事件、校验确认资格并应用生产批次终态。
_Avoid_: 工厂 Agent、Worker 进程、页面状态

## 交付物

**生产档案（Production Record）**：
产品项目累积的结构化事实集合，包括范围、决定、生产事件、闸门证据和版本结果。
_Avoid_: README、聊天历史

**产物（Artifact）**：
工位产生并登记的可查看结果，如文档、代码变更、测试报告、截图、构建包或访问地址。
_Avoid_: 输出、回复

**发布候选（Release Candidate）**：
已经通过当前范围内全部质量闸门、等待最终发布确认的产品版本。
_Avoid_: 已上线、基本完成

**试产（Pilot Run）**：
用真实产品验证工厂本身是否能稳定生产的批次；首个试产对象为小游戏，但试产对象不定义工厂能力边界。
_Avoid_: Demo、假数据演示
