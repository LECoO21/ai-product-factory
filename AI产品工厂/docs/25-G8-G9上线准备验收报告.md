## 3. 真实浏览器验收

使用本地 production standalone 和独立 Chromium 任务空间验收，结果如下：

- 未登录访问首页会进入 `/login`；
- 错误邀请码显示“邀请码不正确”；
- 正确邀请码进入产品工厂首页；
- 退出后返回登录页；
- 退出后 `/api/projects` 返回 401 结构化错误；
- 390px、768px、1280px、1440px 均无横向溢出；
- 四档宽度的主标题、创建按钮和退出入口均可见；
- 未发现来自本应用的 Console 异常、警告或网络失败。

浏览器验收发现并修复了两个问题：

1. 本地 HTTP 运行 production build 时 Secure Cookie 会被浏览器丢弃。现在允许通过 `FACTORY_COOKIE_SECURE=false` 仅用于本地 HTTP 验收；`ENV=prod` 时无论如何都强制 Secure。
2. 手机端侧栏折叠后没有退出入口。现在顶部导航保留紧凑的退出按钮，已验证真实退出成功。
