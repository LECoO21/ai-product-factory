# Naxe 视觉设计规范 V1.1

> 适用范围：AI 产品工厂 WebUI。
>
> 视觉参考：Pilcrow 公开网站的编辑感、留白和排版节奏。
> 品牌边界：不使用 Pilcrow 的名称、乌鸦图形、商业字体、文案、照片或其他受保护资产。

## 1. 品牌

- 对外名称：`Naxe`。
- 产品描述：`AI 产品生产工作台`。
- 语气：冷静、简洁、准确，不使用宣传性技术口号。
- Logo：原创像素 `N`，两条竖向结构代表稳定的生产边界，中间阶梯状对角线代表产品逐步流转。

### Logo 使用

- 默认尺寸：20×20px。
- 最小尺寸：16×16px。
- 只使用单色：浅底使用近黑，深底使用米白。
- 不添加渐变、投影、描边或圆形容器。
- 图形与文字 `Naxe` 的默认间距为 9px。

## 2. 设计原则

1. 先操作，后信息：当前步骤和主要按钮必须比运行记录更显眼。
2. 编辑式排版：大标题使用衬线字体，界面文字使用无衬线字体。
3. 层级靠留白：优先使用留白、字号和细线建立层级，少用卡片、投影和彩色块。
4. 黑白为主：只在错误状态使用红色。
5. 小圆角：所有控件使用 4px 圆角，不使用胶囊按钮。
6. 状态真实：颜色和动画不得替代后端状态。

## 3. 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F8F7F3` | 页面背景 |
| `--surface` | `#FDFCF9` | 输入区和结果面板 |
| `--ink` | `#11110F` | 主文字、主按钮、深色操作区 |
| `--muted` | `#706F6A` | 次要文字 |
| `--line` | `#E4E1D8` | 常规分隔线 |
| `--line-strong` | `#CBC7BC` | 输入框和面板边界 |
| `--danger` | `#A63B2D` | 错误和失败 |

禁止在页面组件中新增无语义的颜色值。

## 4. 字体与字号

### 字体栈

- 展示标题：`Iowan Old Style, Baskerville, Times New Roman, Songti SC, STSong, serif`。
- 界面正文：`Helvetica Neue, Arial, PingFang SC, Microsoft YaHei, sans-serif`。
- 技术内容：`SFMono-Regular, Consolas, monospace`。

所有字体使用系统或免授权 fallback，不下载参考站的商业字体。

### 字号层级

| 层级 | 桌面 | 手机 | 字体 |
| --- | --- | --- | --- |
| 页面 H1 | 42–64px | 38px | 衬线 |
| 重要操作 H2 | 26–48px | 26–34px | 衬线 |
| 结果小标题 | 23px | 23px | 衬线 |
| 正文 | 15px | 14px | 无衬线 |
| 按钮 | 14px | 14px | 无衬线 |
| 导航/状态 | 11–12px | 11–12px | 无衬线 |

## 5. 网格与间距

- 桌面工作台使用 260px 左侧常驻导航，主区独立布局。
- 页面最大宽度：1160px。
- 桌面页面上间距：104px；手机：64px。
- 桌面左右安全边距：16px；手机：12px。
- 主区块间距：48px；手机：36px。
- 列表行高：58–60px。
- 桌面产品列表：两列，列间距 48px；手机单列。

## 6. 组件

### 按钮

- 高度：40px。
- 左右内边距：16px。
- 圆角：4px。
- 主按钮：近黑底 + 米白字。
- 次按钮：透明底 + 灰色边框。
- 深色操作区中的主按钮反转为米白底 + 近黑字。

### 待确认区

- 使用整块近黑背景，与普通信息形成明确差异。
- 桌面高度不少于 150px，手机不少于 210px。
- 标题使用衬线字体，按钮必须可一眼识别。

### 列表与卡片

- 不使用投影。
- 用 1px 横线分隔项目。
- 产品项目使用大留白，不堆叠能力标签或技术说明。

### 表单

- 输入框高度 48px，使用浅色表面和灰色边框。
- 获得焦点后边框变为近黑，不使用发光阴影。
- 错误信息紧邻表单和按钮显示。

### 产品需求输入器

- 使用 14px 圆角的大型纸张区域，这是工作台的唯一大圆角例外。
- 产品类型使用顶部胶囊 Tab，选中项为近黑底。
- 提交按钮使用 40px 圆形箭头，位于底部工具条右侧。

## 7. 响应式

- 默认验收宽度：390px、768px、1280px、1440px。
- 760px 以下进入手机布局。
- 品牌描述在手机端隐藏，保留 Logo、产品和新建入口。
- 六步进度在手机端缩减为“第 N / 6 步 · 当前步骤”。
- 待确认按钮和开始按钮在手机端占满容器宽度。
- 页面不得出现无意横向滚动。

## 8. 动效与无障碍

- hover 只改变边框、颜色或位移 8px 以内，时长 160–180ms。
- 加载动效使用单个像素方块的透明度呼吸，不制造假进度。
- 遵守 `prefers-reduced-motion`。
- 所有可操作元素都必须可通过键盘访问并具有明确焦点。
- 状态不能只依赖颜色，必须同时显示文字。
