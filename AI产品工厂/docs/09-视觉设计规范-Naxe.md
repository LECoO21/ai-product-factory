# Naxe 视觉设计规范 V1.3

> 适用范围：AI 产品工厂 WebUI。
>
> 视觉参考：小云雀工作台的中性灰色阶、紧凑布局、轻量列表和克制动效；保留 Naxe 原创品牌。
> 品牌边界：不使用 Pilcrow 的名称、乌鸦图形、商业字体、文案、照片或其他受保护资产。

## 1. 品牌

- 对外名称：`Naxe`。
- 产品描述：`AI 产品生产工作台`。
- 语气：冷静、简洁、准确，不使用宣传性技术口号。
- Logo：原创像素 `N`，两条竖向结构代表稳定的生产边界，中间阶梯状对角线代表产品逐步流转。

### Logo 使用

- 默认尺寸：20×20px。
- 最小尺寸：16×16px。
- 只使用单色：浅底使用近黑，深底使用米白。
- 不添加渐变、投影、描边或圆形容器。
- 图形与文字 `Naxe` 的默认间距为 9px。

## 2. 设计原则

1. 先操作，后信息：当前步骤和主要按钮必须比运行记录更显眼。
2. 工作台排版：界面正文使用现代无衬线字体，首页提问标题使用系统衬线 fallback。
3. 层级靠色阶：使用中性灰背景、留白和字号建立层级，默认不使用投影。
4. 黑白为主：只在错误状态使用红色。
5. 统一圆角：导航、按钮和列表项 16px，主面板 20px，需求输入器 28px。
6. 状态真实：颜色和动画不得替代后端状态。

## 3. 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#ECECEC` | 主工作台背景 |
| `--sidebar` | `#F2F2F2` | 左侧导航背景 |
| `--surface` | `#F6F6F6` | 输入区、确认区和结果面板 |
| `--surface-hover` | `rgba(72,72,73,0.04)` | 导航与列表 hover |
| `--surface-active` | `rgba(72,72,73,0.08)` | 按下和强调状态 |
| `--ink` | `#000000` | 主文字和主按钮 |
| `--muted` | `rgba(0,0,0,0.52)` | 次要文字 |
| `--line` | `rgba(0,0,0,0.08)` | 常规分隔线 |
| `--line-strong` | `rgba(0,0,0,0.12)` | 聚焦边界 |
| `--danger` | `#A63B2D` | 错误和失败 |

禁止在页面组件中新增无语义的颜色值。

## 4. 字体与字号

### 字体栈

- 品牌字标与首页提问：`Instrument Serif, Iowan Old Style, Baskerville, Times New Roman, Songti SC, STSong, serif`。
- 界面正文：`Albert Sans, PingFang SC, Hiragino Sans GB, Noto Sans SC, Microsoft YaHei UI, Microsoft YaHei, Segoe UI, Arial, sans-serif`。
- 技术内容：`SFMono-Regular, Consolas, monospace`。

所有字体使用系统或免授权 fallback，不下载参考站的商业字体。

### 字号层级

| 层级 | 桌面 | 手机 | 字体 |
| --- | --- | --- | --- |
| 首页提问 H1 | 23px | 23px | 衬线，400 |
| 详情页 H1 | 24–30px | 28px | 无衬线，500 |
| 重要操作 H2 | 17–20px | 17–20px | 无衬线，500–600 |
| 结果小标题 | 18px | 18px | 无衬线，600 |
| 正文 | 14px | 14px | 无衬线 |
| 按钮 | 14px | 14px | 无衬线 |
| 导航/状态 | 11–12px | 11–12px | 无衬线 |

## 5. 网格与间距

- 桌面工作台使用 274px 左侧常驻导航，可收起为 72px，主区同步扩展。
- 页面最大宽度：1024px；需求输入器和待办卡最大宽度 920px。
- 首页桌面上间距：76px；手机：36px（另含移动导航安全区）。
- 桌面左右安全边距：20px；手机：12px。
- 首页主区块间距：20px。
- 列表行高：58–60px。

## 6. 组件

### 按钮

- 高度：40px。
- 左右内边距：16px。
- 圆角：16px。
- 主按钮：近黑底 + 米白字。
- 次按钮：透明底；hover 使用 4% 中性灰背景。
- 深色操作区中的主按钮反转为米白底 + 近黑字。

### 待确认区

- 首页使用紧凑浅灰待办区；运行页确认操作位于真实结果卡底部。
- 只有真实结果和必需产物就绪后才显示确认。
- 主按钮使用近黑底，按钮必须可一眼识别。

### 列表与卡片

- 最近产品只在左侧历史区展示，首页输入器下方不重复展示。
- 历史入口 hover 只增加 4% 中性灰背景，不上移、不增加投影。
- 不堆叠能力标签或技术说明。

### 表单

- 输入框高度 48px，使用浅色表面和灰色边框。
- 获得焦点后使用 1px 中性灰聚焦环，不使用彩色发光。
- 错误信息紧邻表单和按钮显示。

### 产品需求输入器

- 桌面宽度 920px，高度约 164px；使用 28px 圆角的 `#F6F6F6` 输入区域，无默认边框和投影。
- 产品类型使用顶部胶囊 Tab，选中项为近黑底。
- 提交按钮使用 36px 圆形箭头，位于底部工具条右侧。

## 7. 响应式

- 默认验收宽度：390px、768px、1280px、1440px。
- 760px 以下进入手机布局。
- 品牌描述在手机端隐藏，保留 Logo、产品和新建入口。
- 八步进度在手机端缩减为“第 N / 8 步 · 当前步骤”。
- 待确认按钮和开始按钮在手机端占满容器宽度。
- 页面不得出现无意横向滚动。

## 8. 动效与无障碍

- hover 只改变 4% 中性灰背景或文字颜色，时长 150–160ms；按下状态最多下移 1px。
- 侧栏收展约 240ms，抽屉遮罩约 200ms，页面进入约 200ms。
- 加载动效使用单个像素方块的透明度呼吸，不制造假进度。
- 遵守 `prefers-reduced-motion`。
- 所有可操作元素都必须可通过键盘访问并具有明确焦点。
- 状态不能只依赖颜色，必须同时显示文字。
