# Naxe 对话式产品工作台 V1.0

> 参考对象：小云雀网页版已登录工作台。
> 使用边界：只借鉴通用信息架构与交互模式，不使用小云雀的品牌、Logo、文案、图片、视频、图标或其他受保护资产。

## 1. 参考站架构结论

小云雀的核心是单工作台，不是传统项目卡片首页：

1. 左侧常驻导航：创作入口、Agent 入口、资产入口和历史入口。
2. 中央首要区域：先选 Agent 类型，再用大输入框表达创作需求。
3. 输入器底部工具条：能力、模型、偏好、画布和发送操作集中在同一区域。
4. 历史独立成页：支持类型筛选、搜索、列表/网格切换和刷新。
5. 首页下半部用于推荐能力与内容广场，这属于小云雀的内容业务，不适合 Naxe 第一版。

## 2. Naxe 架构映射

| 小云雀模式 | Naxe 实现 | 业务含义 |
| --- | --- | --- |
| 左侧创作导航 | 新建产品、产品 | 从任意页面回到产品入口 |
| 创作历史 | 左侧最近产品 | 直接恢复 SQLite 中的产品档案 |
| Agent 胶囊 Tab | 通用产品、Web 应用、小游戏、内容工具 | 表达产品类型，不把工厂锁死为游戏生产线 |
| 中央对话输入器 | 产品需求输入器 | 先说需求，再建立产品档案 |
| 开始生成 | 创建产品 | 只写入产品档案，不在提交时自动产生 DeepSeek 费用 |
| 生成任务 | 生产批次 | 仍使用现有运行页、SSE、SQLite 和人工确认闸门 |

## 3. 交互规则

- 用户选择产品类型，输入不少于 20 个字的需求。
- 系统用需求首行自动生成产品名称，并将产品类型写入 PRD 上下文。
- 提交后进入产品页；只在用户点击“开始分析”后创建生产批次。
- 待确认批次在输入器下方高亮展示，避免用户不知道流程停在哪里。
- 左侧最近产品最多显示 8 条；产品页与运行页原有最近 20 条规则不变。

## 4. 响应式

- 901px 及以上：260px 左侧常驻导航，主工作台独立滚动。
- 900px 及以下：侧栏收缩为顶部导航，隐藏最近产品列表。
- 390px：产品类型 Tab 横向排列，需求输入器占满可用宽度，不产生横向滚动。

## 5. 未采用内容

- 会员、积分、邀请码和促销公告。
- 作品广场、教程、热点与营销模板。
- 视频模型、角色资产、自由画布和小云雀专属能力。
- 小云雀的移动端桌面布局裁切方式；Naxe 采用真正的响应式顶部导航。
