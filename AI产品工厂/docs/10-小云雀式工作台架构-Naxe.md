# Naxe 对话式产品工作台 V1.2

> 参考对象：小云雀网页版已登录工作台。
> 使用边界：只借鉴通用信息架构与交互模式，不使用小云雀的品牌、Logo、文案、图片、视频、图标或其他受保护资产。

## 1. 参考站架构结论

小云雀的核心是单工作台，不是传统项目卡片首页：

1. 左侧常驻导航：创作入口、Agent 入口、资产入口和历史入口。
2. 中央首要区域：先选 Agent 类型，再用大输入框表达创作需求。
3. 输入器底部工具条：能力、模型、偏好、画布和发送操作集中在同一区域。
4. 历史独立成页：支持类型筛选、搜索、列表/网格切换和刷新。
5. 首页下半部用于推荐能力与内容广场，这属于小云雀的内容业务，不适合 Naxe 第一版。

## 2. Naxe 架构映射

| 小云雀模式 | Naxe 实现 | 业务含义 |
| --- | --- | --- |
| 左侧创作导航 | 新建产品、产品 | 从任意页面回到产品入口 |
| 创作历史 | 左侧最近产品 | 直接恢复 SQLite 中的产品档案 |
| Agent 胶囊 Tab | 描述需求、粘贴 PRD | 支持从一段需求或完整 PRD 开始，不把工厂锁死为游戏生产线 |
| 中央对话输入器 | 产品需求输入器 | 先说需求，再建立产品档案 |
| 开始生成 | 创建产品 | 只写入产品档案，不在提交时自动产生 DeepSeek 费用 |
| 生成任务 | 生产批次 | 仍使用现有运行页、SSE、SQLite 和人工确认闸门 |

## 3. 交互规则

- 用户选择“描述需求”或“粘贴 PRD”，输入不少于 20 个字的内容。
- 系统用内容首行自动生成产品名称，完整内容原样进入后续分析。
- 提交后进入产品页；只在用户点击“开始分析”后创建生产批次。
- 待确认批次在输入器下方用紧凑待办卡展示，避免用户不知道流程停在哪里。
- 待办卡同时提供“取消”和“去确认/查看进度”；取消会停止当前批次并保留已有记录。
- 左侧最近产品最多显示 20 条，并在固定高度内上下滚动。
- 运行页先展示真实结果；只有真实结果和必需产物就绪后，确认操作才出现在结果卡底部。
- 侧栏展开/收起约 240ms，Tab 约 150ms，抽屉遮罩约 200ms；系统开启减少动态效果时停用动画。
- 导航和侧栏历史入口 hover 使用浅灰背景与文字加深，不使用卡片浮起或大阴影。
- 首页输入器下方不重复展示最近产品；产品恢复入口统一收敛到左侧历史区。

## 4. 视觉取值依据

2026-08-28 使用真实登录态浏览器检查参考站桌面工作台，采用以下可复用通用规则：

| 证据 ID | 参考站观察 | Naxe 映射 |
| --- | --- | --- |
| `E-XYQ-VIS-001` | 主区 `#ECECEC`，侧栏 `#F2F2F2` | 对应 `--paper` 与 `--sidebar` |
| `E-XYQ-TYPE-001` | 首页标题约 23px、400、1.5 行高 | Naxe 首页提问标题使用相同层级和系统 fallback |
| `E-XYQ-COMP-001` | 输入器 920×164px、28px 圆角、`#F6F6F6`、无边框无阴影 | Naxe 需求输入器按同一尺寸层级实现 |
| `E-XYQ-NAV-001` | 侧栏 274px；导航行 40px、16px 圆角 | Naxe 桌面侧栏与主导航采用相同几何规则 |
| `E-XYQ-HOVER-001` | hover 克制，不产生大范围位移和投影 | Naxe 只改变灰色背景、文字或 1px 按下位移 |

## 5. 响应式

- 901px 及以上：274px 左侧常驻导航，可收起到 72px，主工作台同步扩展。
- 900px 及以下：侧栏改为左侧抽屉，使用独立菜单按钮、遮罩和关闭入口；抽屉内保留最近产品。
- 390px：输入方式 Tab 横向排列，需求输入器占满可用宽度，不产生横向滚动。

## 6. 未采用内容

- 会员、积分、邀请码和促销公告。
- 作品广场、教程、热点与营销模板。
- 视频模型、角色资产、自由画布和小云雀专属能力。
- 小云雀的移动端桌面布局裁切方式；Naxe 采用真正的响应式抽屉导航。
